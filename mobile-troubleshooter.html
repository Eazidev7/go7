Troubleshooting Steps

  1. Check if the development server is running

    The server should be running on http://localhost:5173 or another port. Look for a terminal window showing the Vite server output.

  2. Start the development server

    If the server isn't running, open a terminal in the Go7 folder and run:

    npm run dev

  3. Try the mobile simulator

    Once the server is running, you can access the mobile simulator at:

    http://localhost:5173/mobile-simulator.html

  4. Try using port 5174 or 5175

    If port 5173 doesn't work, try running the server on a different port:

    npm run dev -- --port 5174

    Then access: http://localhost:5174/mobile-simulator.html

  5. Try using the simplified script

    Run the batch file that automatically starts the server and opens the simulator:

    start-mobile-simulator.bat

Need More Help?

If you're still having trouble, try these additional steps:

  1. Check the console for error messages
  2. Make sure port 5173, 5174, or 5175 is not in use by another application
  3. Try restarting your computer
  4. Check if any firewall is blocking the connection
  5. Review the documentation in MOBILE_TESTING_GUIDE_EXPANDED.md
