🚀 Usage & Integration

1. Basic Usage

// Navigate to tracking page // URL: /track/ORD-001 // The page automatically: // - Fetches order data from Firestore // - Subscribes to real-time updates // - Renders DeliveryMap with GPS tracking // - Enables chat functionality

2. DeliveryMap Integration

<DeliveryMap pickup={order.pickup} // From order document dropoff={order.dropoff} // From order document fee={order.fee} // From order document riderId={order.riderId} // From order document />

3. Real-time Subscriptions

// Order updates const orderDocRef = doc(db, 'orders', orderId); const unsubscribe = onSnapshot(orderDocRef, (doc) => { setOrder(doc.data()); }); // Chat messages const chatRef = collection(db, 'chats', orderId, 'messages'); const chatQuery = query(chatRef, orderBy('timestamp', 'asc')); const unsubscribe = onSnapshot(chatQuery, (snapshot) => { setChatMessages(snapshot.docs.map(doc => doc.data())); });
