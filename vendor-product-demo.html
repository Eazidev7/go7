🚀 Quick Start

Development Server Running:
http://localhost:3000/
  1. Access Vendor Products Page
    Navigate to: http://localhost:3000/vendor/{your-vendor-id}/products
  2. Deploy Cloud Functions
    cd functions && npm run deploy
  3. Create a Product
    Click "Add Product", fill form with numeric price, upload image
  4. Verify Global Sync
    Check Firebase Console → /products collection for mirrored product
  5. Add Addons
    Select product, click "Add Addon", upload addon image
  6. Test Real-time Updates
    Change product in Firestore Console, watch UI update automatically

💻 Usage Example

Create Product with Image Upload
import { VendorProductService } from './services/vendorProductService';

const newProduct = await VendorProductService.createProduct(
  vendorId,
  {
    name: 'Jollof Rice',
    description: 'Delicious Nigerian jollof rice',
    price: 1500,  // ⚠️ MUST BE NUMBER
    currency: 'NGN',
    measurementType: 'portion',
    minQty: 1,
    maxQty: 50,
    available: true,
    category: 'Food'
  },
  imageFile  // Optional File object
);

console.log('Product created:', newProduct.id);
Real-time Product Listener
const unsubscribe = VendorProductService.subscribeToVendorProducts(
  vendorId,
  (products) => {
    console.log('Products updated:', products);
    setProducts(products);
  },
  (error) => {
    console.error('Listener error:', error);
  }
);

// Cleanup
return () => unsubscribe();
