# GO7 — Delivery & Errands Platform

A live 24/7 multi-role delivery marketplace running in Abeokuta, Nigeria — customer, vendor, rider, and admin apps plus native Android builds, all from one codebase.

**Live:** https://go7.ng

## Highlights

- Real-time order tracking on live maps (Leaflet/MapLibre)
- Paystack payments + dedicated virtual account (DVA) wallet funding
- Push notifications (FCM), installable PWA, native Android via Capacitor
- Zero-downtime verify-before-cutover deploy pipeline
- Firebase backend: Firestore, Cloud Functions, Storage, Auth

## Stack

`React` `Vite` `TypeScript` `Firebase (Firestore, Functions, FCM, Storage)` `Paystack` `Capacitor` `Leaflet / MapLibre` `Zustand` `PWA`

> Public snapshot — environment configs, credentials, and deployment scripts are intentionally excluded. Requires your own `.env` files and Firebase/Paystack keys to run.
