📊 Firestore Database Structure

The component expects rider data in the following Firestore structure:

Collection: riders Document ID: {riderId} Document Structure: { "lat": 7.1475, // Rider latitude (number) "lng": 3.3619, // Rider longitude (number) "status": "en_route", // Order status (string) "timestamp": [Firestore ServerTimestamp], "riderId": "AKEEM01" // Rider identifier (optional) } Status Values: - "accepted" → Order Accepted - "picked_up" → Order Picked Up - "en_route" → Rider En Route - "delivered" → Order Delivered

🚀 Usage Example

import DeliveryMap from './components/DeliveryMap'; function App() { return ( <DeliveryMap pickup={[3.3619, 7.1475]} // Pickup coordinates (Abeokuta) dropoff={[3.3700, 7.1530]} // Dropoff coordinates fee="₦1450" // Delivery fee riderId="AKEEM01" // Must match Firestore document ID /> ); }

⚙️ Setup Instructions

  1. Firebase Configuration
    Ensure your Firebase project is configured with Firestore enabled
  2. Environment Variables
    Set up Firebase config in your environment variables
  3. Firestore Collection
    Create a collection named riders in your Firestore database
  4. Install Dependencies
    npm install maplibre-gl firebase
  5. Import Component
    Import and use the DeliveryMap component in your app
