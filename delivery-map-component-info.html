🗺️ Go7 DeliveryMap Component

✅ Component successfully created at: src/components/DeliveryMap.tsx

A reusable React TypeScript component for delivery tracking with MapLibre GL and custom PNG markers.

📋 Component Interface

interface DeliveryMapProps { pickup: [number, number]; // [longitude, latitude] dropoff: [number, number]; // [longitude, latitude] fee: string; // e.g., "₦1450" riderId: string; // e.g., "AKEEM01" }

🚀 Usage Example

import DeliveryMap from './components/DeliveryMap'; function App() { return ( <DeliveryMap pickup={[3.3619, 7.1475]} dropoff={[3.3700, 7.1530]} fee="₦1450" riderId="AKEEM01" /> ); }

🎨 Features Implemented

  • ✅ MapLibre GL Integration - MapTiler cartoon style
  • ✅ Custom PNG Markers - bag.png, shop.png, scooter.png, olumo.png
  • ✅ Dashed Route Line - Red route between pickup and dropoff
  • ✅ Fee Display Box - Styled fee amount at route midpoint
  • ✅ GPS Simulation - Real-time rider movement every 2 seconds
  • ✅ Smooth Animation - requestAnimationFrame interpolation
  • ✅ Order Status Tracker - Accepted → Picked Up → En Route → Delivered
  • ✅ Interactive Markers - Popup tooltips on hover
  • ✅ TypeScript Support - Full type safety
  • ✅ Responsive Design - Works on mobile and desktop
