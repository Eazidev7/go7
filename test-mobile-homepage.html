🧪 Mobile Homepage Test

📱 Test Instructions:

  1. Open the main app at localhost:3001
  2. Resize your browser to mobile width (375px) or use device tools
  3. Check that the mobile version loads (HomePageTailwind)
  4. Verify Firebase vendors load in "Trending" and "For You"
  5. Test vendor card navigation

✅ Expected Results:

  • Desktop (>768px): Shows Hero homepage
  • Mobile (≤768px): Shows Tailwind homepage
  • Vendors: Real Firebase data, not mock placeholders
  • Categories: Modern Heroicons (truck, map pin, etc.)
  • Navigation: Vendor cards go to /vendor/dashboard/{id}
  • Images: Business-specific fallbacks when needed

🐛 Debug Checklist:

If vendors don't load, check browser console for:

  • 🔥 Firebase connection logs
  • 📊 Vendor query results
  • 🖼️ Image loading errors
  • 🔗 Navigation click events
  • 📱 Device detection logs
